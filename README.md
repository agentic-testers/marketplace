# agentic-testers marketplace

Claude Code plugins for software testers and quality engineers.

## Add the marketplace

In Claude Code, type `/plugins`, open **Marketplaces** and add `agentic-testers/marketplace`. From the terminal:

```
claude plugin marketplace add agentic-testers/marketplace
```

## Plugins

| Plugin | What it does | Install |
|--------|--------------|---------|
| [AgenSDET](https://agentic-testers.github.io/agensdet/) | Helps manual QA engineers start test automation with Playwright and Azure Pipelines. | `agensdet@agentic-testers` |
